## Overview

**BazarDor (বাজার দর)** is a web application designed to make everyday market prices easier to access and understand in Bangladesh.

The platform brings product discovery, category-based browsing, pricing information, and user account functionality together in a clean and responsive interface.

Built with modern web technologies, BazarDor aims to provide a convenient experience for users who want to explore essential products and make more informed shopping decisions.

## Key Features

- **Market Price Insights** — Explore product prices and available price-change information.
- **Product Discovery** — Browse everyday essentials through an organized interface.
- **Category-Based Browsing** — Find products by category and use available sorting options.
- **Price Comparison** — Review available pricing information across products or markets.
- **User Authentication** — Sign in and manage access through supported authentication methods.
- **Profile Management** — View account information and update profile details.
- **Responsive Design** — Access the application across mobile phones, tablets, and desktop devices.

## Getting Started

Follow these steps to run BazarDor locally.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/mrfizz17/Bazar_dor_project.git
```

**2. Navigate to the project directory**

```bash
cd Bazar_dor_project
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file in the root directory.

Add the environment variables required by your project, such as database connection details, authentication secrets, OAuth credentials, and API URLs.

Use the exact variable names expected by your source code. Never commit private credentials or secrets to GitHub.

**5. Start the development server**

```bash
npm run dev
```

**6. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
